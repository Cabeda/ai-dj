# ai-dj

A generative radio DJ: it plays a live set, listens to its own output, and
evolves the music with an LLM — either on its own or with a human co-working
through the UI.

## Language

**Backend** (Sound backend):
The component that turns a script into sound. Pluggable, so the DJ logic does
not depend on a particular engine.
_Avoid_: engine, synth, player.

**Script**:
The playable code that defines the current set. Generated by the DJ, editable by
the human, and executed by the backend.
_Avoid_: program, patch, code.

**Layer** (Voice):
One named part of the arrangement — a kick, a bass, a pad; or a violin, a cello.
The DJ evolves one layer at a time.
_Avoid_: track, channel, instrument.

**Instrument**:
A named timbre the DJ may play a layer with, drawn from the instrument palette.
_Avoid_: sound, voice, preset.

**Instrument palette**:
The closed set of instruments the model is allowed to choose from, each with a
per-backend realisation. Filters by what the active backend can play.
_Avoid_: sound bank, library.

**Session**:
A saved, numbered set that can be resumed.
_Avoid_: project, song, track.

**Station**:
An always-on live set you tune into — the thing the website plays. One station
runs continuously whether or not anyone is listening. Distinct from a Session,
which is a saved set.
_Avoid_: channel, stream.

**Steering**:
One visitor's direction to the Station — a nudge toward a mood, a tempo, a
change. Open to everyone; each one passes the bad-words guard before the loop
reads it.
_Avoid_: vote, request.

**Archetype**:
A named, curated starting point for a set — a genre or an ensemble.
_Avoid_: template, preset, style.

**Casting**:
Choosing an archetype and its parameters from a vibe, rather than composing the
whole set from scratch.
_Avoid_: seeding, bootstrapping.

**Starter** (First script):
The script played at the very start of a session.
_Avoid_: intro, default.

**Hearing**:
The model's description of the audio it was given.
_Avoid_: analysis, transcription.

**Patch** (Op):
A single change to one layer.
_Avoid_: diff, edit, update.

**Evolve**:
One incremental step of the set, changing a single layer.
_Avoid_: update, iterate, morph.

**Guide feedback**:
Human direction meant to nudge the set incrementally.
_Avoid_: feedback, suggestion.

**Replace feedback**:
Human direction that asks for a whole new set — a full vibe swap.
_Avoid_: reset, restart, override.

**Language**:
The surface a set is written in — `sonic_pi` (Ruby DSL) or `strudel`
(JavaScript patterns). Identifies the script's syntax, its reference document,
and how it is validated. Distinct from the backend: Sonic Pi is always
`sonic_pi`, Strudel is always `strudel`.
_Avoid_: dialect, format.
